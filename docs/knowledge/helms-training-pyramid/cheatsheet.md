# Cheatsheet — Decision Rules & Thresholds

## The Pyramid Order (audit top-down only after bottom is fixed)
Adherence → Volume/Intensity/Frequency → Progression → Exercise Selection → Rest Periods → Tempo. **When results stall, audit from the bottom up.**

## Core Prescriptions (start here, adjust by response)
| Variable | Rule |
|---|---|
| Volume | Novice 10–12 · Intermediate 13–15 · Advanced 16–20 sets/muscle/week |
| Frequency | 2+×/week per muscle/movement (novice 2–3×, int 3–4×, adv 3–5×) |
| Strength intensity | ⅔–¾ of sets in 1–6 reps, rest 6–15, @ 5–10 RPE |
| Hypertrophy intensity | ⅔–¾ of sets in 6–12 reps, rest 1–6 & 12–20, @ 5–10 RPE |
| Days/week | 3–5 for 90% of people (2 only for novices) |
| Specificity | Competition lifts = 50–75% of a strength program's volume |

## RPE / Load Quick Conversion
10 = failure · 9 = 1 RIR · 8 = 2 RIR · 7 = 3 RIR · 5–6 = 4–6 RIR.
Reps @ %1RM (averages): 100%→1 · 95%→2 · 90%→3–4 · 85%→5–6 · 80%→7–8 · 75%→9–10 · 70%→11–12.
Always pair %1RM with an RPE range; adjust load if set 1 lands outside it.

## Rep/RPE by Exercise Class
| Class | Reps | RPE |
|---|---|---|
| Lower FW compound | 3–8 | 5–8 |
| Lower machine compound | 6–12 | 6–9 |
| Isolation (either) | 8–20 | 7–10 |
| Upper FW compound | 3–12 | 6–9 |
| Main lift — strength / volume / technique | 1–5 @ 7–10 / 4–8 @ 5–8 / 1–3 @ 4–7 | |

## "I'm plateaued" — run this tree
1. Sleeping 8+ h? Surplus? Protein ≥0.7 g/lb? Honest RPE? 2×/week frequency? Technique solid? → any "no": fix it, run another mesocycle.
2. Recovering? (dread, worse sleep, falling loads/reps, worse stress, worse aches — 2+ yes = no) → **not recovering**: light week; if fatigue returns instantly, cut ~20% of sets permanently. **Recovering**: add 1–2 sets/muscle (~10%) on the stalled lifts.
3. Still stuck at your level's progression rate (novice: halved increments; intermediate: +2.5 kg/cycle) → move up a progression model.

## Progression Model by Training Age
| Level | Compounds | Isolation |
|---|---|---|
| Novice | Linear load (+5/+10 lb per session; 2 fails → −10%) | Smallest increments / every-other-session |
| Intermediate | Wave loading (8→7→6, +load weekly; deload after wave per checklist) | Double progression (reps→top, then load) |
| Advanced | Blocks: accumulation (sets up, RPE 5–8) → intensification (sets down, RPE→9+) → taper/test | Double progression, RPE ranges |

## Deload Triggers & Recipes
- Checklist (post-meso): dread / sleep / falling loads-reps / stress / aches — **2+ yes = deload**; mandatory by 3rd meso.
- Novice: −10% load after 2 failed sessions. Post-novice: ½ volume, same loads, −2 RPE. Wave: lowest wave load/reps @ ⅔ sets. Block: repeat wk3 @ ⅔ sets, −1 RPE, −5%.
- Only-aches week: normal volume at 12–20 reps, or BFR @ 20–30% 1RM on single-joint work (wrap 7/10, no tingling/discoloration).
- Before a volume block: intro week @ ~75% volume, −1 RPE.

## Failure & Effort Rules
- Compounds: never to failure; technical failure only when testing. First-set RPE targets keep later sets completable.
- Failure is cheap on isolation/machines — use it there (last sets, drop sets, BFR).
- Cutting sets short of failure costs nothing in gains (meta-analyses) and saves recovery.

## Rest & Tempo
- Rest: ≥1.5 min isolation, ≥2.5 min compounds; otherwise rest until ready. No hypertrophy benefit to short rests has ever been shown.
- APS (opposite muscles only): ~2 min compounds, ~1 min isolation; never around squat/deadlift/lunge.
- Tempo: controlled eccentric, maximal-intent concentric. Reps ≥10 s = negative for growth. Never slow down so much the load/reps drop.

## Volume Counting
- Count hard sets per muscle; primary and secondary count 1:1, but ensure direct work dominates. Glutes/arms/anterior delts read high from overlap; calves/hams read low.
- Warm-ups heavy enough to be work count too.

## Meet-Week (Powerlifting) Quick Protocol
4 wk out: strength days at 1–3 reps → wk 3: deload non-competition lifts → wk 4: openers @ RPE 7.5–8.5, 7 days out → 24–48 h out: singles @ RPE 4–5 on the big 3, nothing else → compete. Attempts: opener ≈ 3RM, second ≈ 2RM, third = 2.5 kg PR. Bodybuilder peak week: 8–20 reps @ RPE 6–8.5, no soreness-makers, split done 2–3 days out, optional 30-min pump @ ≤6 RPE.

## Cutting
Mild cut: change nothing. Aggressive/long: drop one volume tier ~⅓ into the diet, deload automatically every meso, trust RPE over percentages.

## Injury
If it hurts: alter ROM, reduce load, or swap the movement. Not gone in weeks → sports PT. Don't train through pain; don't flee all training either.
