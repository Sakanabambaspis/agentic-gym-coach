# Patterns & Techniques

## Progression Patterns

**Linear (single) progression — novice compounds**
**When to use**: training age novice; most lifts still progress session/session or week/week.
**How**: +5 lb/session (upper) or +10 lb (squat/deadlift/hinge); same sets/reps. Miss target reps → repeat load. Miss 2 consecutive → −10%, rebuild. Stall at halved increments → graduate to intermediate.
**Trade-offs**: fastest possible progress; expires quickly and invisibly — track stalls across *most* lifts.

**Wave loading (linear periodization) — intermediate compounds**
**When to use**: can no longer add load at constant reps.
**How**: 3-week waves — load up, reps down (8→7→6 or 12→10→8); week 4 deload per checklist or restart heavier (+smallest increment). Widen ranges if failure intrudes.
**Trade-offs**: steady volume-load growth wave-over-wave; requires RPE calibration.

**Double progression — isolation (and dumbbell work with big jumps)**
**When to use**: small exercises where fixed load jumps are huge in relative terms (5 lb on a 50 lb curl = 10%).
**How**: hold load, add reps to top of range (3×12→3×15), then +load, rebuild. Deload week = bottom of range, 2 sets.
**Trade-offs**: slower feeling, but the only sustainable path for small lifts.

**Block periodization — advanced compounds**
**When to use**: progress invisible month-to-month; peaking matters.
**How**: accumulation (~6 wk: sets 12→22, RPE 5–8) → intensification (~4 wk: sets 22→12, RPE→9+) → realization (~2 wk taper + test or rinse-and-repeat).
**Trade-offs**: best long-term structure; overkill before advanced.

## Autoregulation Patterns

**Post-block deload checklist** — After each mesocycle ask: dreading the gym? sleep worse? loads/reps decreasing? stress worse? aches worse? 0–1 yes → proceed; 2+ yes → deload; only aches → 12–20-rep week or BFR. Mandatory every 3rd mesocycle regardless.

**RPE-capped percentage prescriptions** — Program "3×8 @ 70% @ 6–8 RPE": if set 1 misses the RPE window, adjust load. The RPE range absorbs individual rep-endurance differences that %1RM cannot.

**Flexible periodization** — Choose the easy/medium/hard session of the week by readiness (study-supported strength edge over fixed order). Float training days (2–3-day weeks) or off days (4+-day weeks).

## Fatigue-Management Patterns

**Novice deload**: two failed sessions → −10% load, same reps/sets, return to failing load next week.
**Post-novice deload**: ~half volume at similar loads, ~2 RPE lower (3×10×200 → 2×8×200).
**Intermediate wave deload**: lowest reps + lowest load of the just-finished wave, ⅔ sets.
**Advanced block deload**: repeat week 3 with ⅔ sets, RPE −1, %1RM −5%.
**Volume cuts**: chronically under-recovered → −20% of sets across the board.
**Volume adds**: plateaued while recovering → +1–2 sets per muscle (~10%), placed on the stalled lift.

**Intro week** — before a volume block: ~75% of planned volume, ~1 RPE lower. Pairing rule: Volume block → deload → Intensity block; Intensity block → intro week → Volume block.

## Time-Efficiency Patterns

**Antagonist paired sets** — opposite muscle groups only; ~2 min spacing compounds, ~1 min isolation; banned around squats/deadlifts/lunges (and leg-drive bench).
**Rest-pause** — one load, failure + 20–30 s rests to rep target; accessories only; place late in the week. Track total reps @ load.
**Drop sets** — failure + load drops (80→65→50→40→30%); last-isolation-when-late-for-time; compare only to other drop-set sessions.

## Exercise-Selection Patterns

**Specificity budget** — strength: 50–75% of volume from competition lifts; hypertrophy: 1–2 compounds + 1–3 isolations per muscle group, compounds static across mesocycles, isolations rotatable.
**Weak-point triage** — structural → substitute the exercise; activation/technique → re-grip/re-cue/re-learn; weak link → direct accessory attack (e.g. rack holds for grip).
**Fault-punishing variants** — pick variations that fail fast when technique breaks (front squat punishes squat-mornings) to reinforce positions near max.
**Sticking-point tools, ranked** — pauses for motor-learning chunks (not *at* the stall) → isometrics at the weak angle → fault-punishing variants → speed work ± bands/chains (individual responders only).
**Order rule** — compounds first; weak-point isolation first only if it can't impair the compounds (biceps pre-bench OK; nothing before squats/deadlifts).

## Cutting Patterns

**Diet adjustment** — mild cut: change nothing. Aggressive/long cut: drop one volume tier around the first third; deload automatically every mesocycle; trust RPE over percentages as performance gets noisy.

## Warm-Up Pattern

**Sequence** — (optional) 5-min easy cardio → dynamic prep (leg swings, arm circles, cross-body slaps, walking lunges w/ rotation) → ramp-up sets (1–5-rep work: 50/60/70/80/90% × 5/5/4/3/2/1; 6+-rep work: 50%×8, 70%×4, 90%×2). No long static stretching of muscles about to be trained (short/gentle, foam rolling, or dynamic-after are the workarounds).
